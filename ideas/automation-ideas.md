# Automation Ideas

## Purpose

This document collects practical automation ideas for public administration, office productivity, security operations, and documentation workflows.

The goal is to identify small but useful automation projects that can later be developed using AI coding tools such as Codex.

---

## Idea Evaluation Criteria

A good automation idea usually has the following characteristics:

- [ ] Repetitive task
- [ ] Clear input
- [ ] Clear output
- [ ] Rule-based process
- [ ] Low risk if used as a draft or assistant tool

## Notes

Start with assistant tools, not fully automated decision-making tools.

Good first projects should help with:

1. Drafting
2. Summarizing
3. Classifying
4. Checking
5. Organizing

Avoid projects that make final decisions without human review.
