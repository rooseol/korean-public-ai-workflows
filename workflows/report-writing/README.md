# Report Writing Workflow

## Purpose

This workflow helps generate structured administrative and operational reports using AI assistance.

It focuses on clarity, consistency, and professional documentation style.

---

## Report Components

| Section | Description |
|---|---|
| Summary | Overall situation overview |
| Background | Context and cause |
| Actions | Measures taken |
| Status | Current condition |
| Next Steps | Follow-up actions |

---

## Prompt (Korean)

```text
다음 내용을 기반으로 행정 보고서 초안을 작성하세요.

출력 형식:
- 개요
- 배경
- 조치 사항
- 현재 상태
- 향후 계획

규칙:
- 보고서 스타일 유지
- 간결하고 명확하게 작성
- 핵심 위주 정리
- 객관적인 표현 사용
```

---

## Example

### Input

- 네트워크 장애 발생
- 일부 시스템 접속 불가
- 장비 점검 완료
- 현재 정상 복구 상태

---

### Output

#### 개요
- 네트워크 장애로 일부 시스템 접속 지연 발생

#### 조치 사항
- 네트워크 장비 점검 및 복구 완료

#### 현재 상태
- 정상 운영 중
