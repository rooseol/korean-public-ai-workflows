# Meeting Preparation Workflow

## Purpose

This workflow helps prepare meetings by organizing agendas, objectives, participants, and expected outcomes.

---

## Preparation Checklist

- [ ] Define meeting objective
- [ ] Prepare agenda
- [ ] Identify participants
- [ ] Gather supporting documents
- [ ] Define expected outcomes

---

## Prompt (Korean)

```text
다음 회의 주제를 바탕으로 회의 준비 문서를 작성하세요.

포함 항목:
- 회의 목적
- 안건
- 참석 대상
- 준비 자료
- 기대 결과
```

---

## Example

### Input

신규 네트워크 장비 도입 검토

### Output

#### 회의 목적
신규 장비 도입 필요성 검토

#### 안건
- 현재 장비 현황
- 신규 장비 비교
- 예산 검토

#### 기대 결과
도입 여부 결정
