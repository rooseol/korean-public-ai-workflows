# Meeting Summary Workflow

## Purpose

This workflow helps summarize meetings into a structured format suitable for Korean public administration and office environments.

---

## Output Format

- Main Agenda
- Decisions
- Action Items
- Responsible Person
- Risks

---

## Prompt (Korean)

```text
다음 회의 내용을 아래 형식으로 정리하세요.

## 출력 형식
- 주요 안건
- 결정 사항
- 담당자
- 일정
- 위험 요소

## 규칙
- 핵심만 간결하게 작성
- 불필요한 표현 제거
- 공공기관 보고 스타일 유지
```

---

## Example

### Input
- 서버 교체 일정 논의
- 예산 부족 문제 발생
- 6월 말까지 완료 필요

### Output

#### 주요 안건
- 서버 교체 일정 검토

#### 결정 사항
- 6월 말까지 교체 진행

#### 위험 요소
- 예산 부족 가능성 존재
