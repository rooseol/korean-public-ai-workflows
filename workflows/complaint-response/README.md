# Complaint Response Workflow

## Purpose

This workflow helps create structured and professional responses for public complaints and administrative inquiries.

It is designed to improve clarity, consistency, and professionalism in written communication.

---

## Response Principles

- Maintain respectful tone
- Avoid emotional expressions
- Provide factual explanations
- Keep administrative writing style
- Focus on clear communication

---

## Workflow Checklist

- [ ] Identify the core complaint
- [ ] Remove emotional language
- [ ] Verify factual information
- [ ] Write clear response
- [ ] Review tone and clarity

---

## Prompt (Korean)

```text
다음 민원 내용을 바탕으로 공식적인 답변 초안을 작성하세요.

규칙:
- 감정적 표현 최소화
- 정중한 표현 유지
- 사실 중심으로 작성
- 행정기관 답변 스타일 유지
- 불필요한 표현 제거
```

---

## Example

### Input

"담당자의 설명이 부족했고 처리 과정이 늦었습니다."

---

### Output

안녕하세요.

문의하신 사항에 대해 불편을 드린 점 양해 부탁드립니다.

관련 사항을 확인한 결과, 처리 과정에서 안내가 충분하지 않았던 부분이 확인되었습니다. 향후 보다 신속하고 명확한 안내가 이루어질 수 있도록 개선하겠습니다.

감사합니다.
